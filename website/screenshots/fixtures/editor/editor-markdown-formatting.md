# Mandolin Basics

The mandolin is a **small**, _double-strung_ instrument played with a pick.

- Four courses of paired strings
- Tuned in fifths: G–D–A–E
  - The same intervals as a violin
- Played with a plectrum, often in tremolo

> A tremolo is a rapid down-up picking that sustains a single note.

---

Set the action with the `truss rod` and a fresh set of strings.
