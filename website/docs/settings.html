Docs/Settings

Settings

Twelve tabs, each a different corner of how Minerva behaves. Some are about the editor itself, some about the AI, some about where things get filed or fetched from. None of it is per-note — everything here is per-machine or per-project, and most of it applies the moment you change it, no restart required.

The twelve tabs

Editor
Tab size, wrapping, line numbers, and other editing preferences.
Appearance
Theme and content font — both apply live, per machine.
Behaviors
App-wide toggles, plus re-enabling any dialog you silenced.
Notes
Where new notes from refactoring and excerpts land.
Formatter
Every markdown normalization rule, individually toggleable.
Bibliography
Citation style, locale, and importing more of each.
Web
Master switch and domain lists for web_search and web_fetch.
Sources
Upstream tag import and per-site fetch privileges.
Clipper
Turn on the browser extension and see its pairing code.
Compute
Which Python interpreter runs your compute cells.
AI
Default model, effort, API key, and voice dictation.
Skills
Import skills and set per-skill model overrides.
