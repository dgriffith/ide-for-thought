Docs/Navigation/Quick switch

Quick switch

Press ⌘P (or CtrlP) and start typing to jump straight to a note, a source, or a saved query by name — no mouse, no browsing the sidebar tree. Results narrow as you type, ranked by how well they match; arrow keys and Enter take you the rest of the way.

Opening it

Quick switch lives in its own dialog, titled "Go to…" — GotoNoteDialog.svelte in the source tree, though nothing in the UI calls it that. The shortcut is ⌘P / CtrlP, deliberately following Obsidian's convention for quick-open rather than the VS Code / Linear-style ⌘K Minerva uses for its command palette.

Not ⌘O

⌘O / CtrlO is bound to Open Thoughtbase… — it opens a different knowledge-base project entirely. It has nothing to do with switching notes inside the current one. If quick switch doesn't seem to be responding, check you're pressing P, not O.

A multi-scope picker

Quick switch isn't limited to notes. Whenever the current project has sources or saved queries, the dialog shows a row of filter chips and searches across all three kinds at once:

All
Default scope. Matches notes, sources, and saved queries together, each result labeled with a kind icon.
Notes
Matches against a note's title and its relative path in the project tree.
Sources
Matches against a source's title and byline. Only shown when the project has at least one source.
Queries
Matches against a saved query's name and description. Only shown when the project has at least one saved query.

Each chip shows a live count. If a project has no sources and no saved queries yet, the chip row doesn't appear at all and quick switch behaves as a plain notes picker.

How matching works

As you type, every candidate in the active scope is scored against the query and re-sorted; a query that matches nothing scores zero and drops out of the list. Several matching strategies are tried, from most to least exact:

Substring — name
The query appears anywhere in the title. Highest-ranked match.
First letters
Each typed character matches the first letter of successive words — rf matches "Raft Foundations."
camelCase initials
Each typed character matches a capitalized letter in the name, the way it would in an identifier.
Substring — path / secondary
The query appears in the note's relative path, a source's byline, or a query's description.
Fuzzy subsequence
The typed characters appear in order somewhere in the name (or, ranked lower still, the secondary field) — not necessarily together. The lowest-ranked way to match, and a useful fallback when you only half-remember a title.

With an empty query, every item in the active scope scores zero and the list falls back to the project's original file-tree order — it is not sorted by recency. Each row does show a relative modification time, but that's informational only; it doesn't drive the ranking.

Regex queries

If what you type contains a regex metacharacter (. * + ? ^ $ { } ( ) | [ ] \), Minerva tries it as a regular expression against names and paths first, falling back to the fuzzy strategies above if the pattern is invalid. This is a real capability, not an edge case to avoid — typing something like ^draft- or 2024-\d\d narrows results the way a full regex search would, without leaving the quick switch dialog.

Keyboard control

Once the dialog is open, the mouse is optional:

↑ / ↓
Move the highlighted result.
Enter
Open the highlighted result — a note opens in the editor, a source opens in the Source viewer, a saved query runs in a query tab.
Esc
Close the dialog without navigating.

The footer echoes this — ↑↓ navigate · ↵ open · esc close — alongside a running count of the current result list, and the input carries a small "⌘P" hint chip so the shortcut is visible even if you opened the dialog some other way.

Quick switch vs. the command palette vs. Search

Minerva has three separate ways to jump around, and they're deliberately not merged into one box:

Quick switch — ⌘P
Jump to a thing — a note, source, or saved query — by title or path. No actions, no commands.
Command palette — ⌘K
Run an action — a menu command, a skill, a setting — by name. See Command palette.
Search
Find a passage — full-text search over note body content, not just titles and paths. See Search.

If you know roughly what a note is called, quick switch is the fastest route to it. If you're trying to recall something you know you wrote but can't remember the title of, reach for Search instead — quick switch never looks inside a note's content.
