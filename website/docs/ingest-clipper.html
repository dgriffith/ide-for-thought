Docs/Ingest/Browser clipper

Browser clipper

A Chrome extension that saves the page you're reading into your thoughtbase without leaving the browser — your current selection rides along as a linked excerpt. The browser sends Minerva the rendered HTML it can see, so authenticated and paywalled pages extract correctly; the app does the actual Readability extraction, not the extension.

Install & pair

1. Build
pnpm build:clipper → clipper/dist/. Chrome only for now; installs unpacked (Developer mode → Load unpacked → pick clipper/dist) — a Chrome Web Store listing is still on the way.
2. Pin it
Click the puzzle-piece Extensions icon in Chrome's toolbar and pin Minerva Clipper so its button stays visible.
3. Pair
In Minerva: Settings → Browser Clipper → enable it with a thoughtbase open, and copy the pairing code shown there.
4. Confirm
In the extension's options page, paste the pairing code and pair. Test connection confirms the secret is valid and whether a thoughtbase is currently open to receive captures.

Two ways to capture

Curate, then save
Click the toolbar button to open a popup showing the page title and the exact source id the save will produce (e.g. arxiv-2604.18561) before you commit — add tags and a note, then hit Save.
Instant save
Cmd+Shift+S / Ctrl+Shift+S on any page — no popup, defaults only. A badge flashes ✓ on success, ! on failure, ? if the extension isn't paired yet.

Either way, a text selection on the page at the moment you capture is saved as a linked excerpt on the resulting source — the same excerpt mechanism used elsewhere in Minerva, anchored to the captured text.

Security posture, briefly

The extension talks to a loopback-only server (127.0.0.1) that Minerva runs while a thoughtbase is open, authenticating every request with the shared secret from pairing. The endpoint only accepts requests from the extension's own chrome-extension:// origin — a content script or the page itself can't reach it directly, which is why capture (reading the page) and send (talking to Minerva) are handled by separate parts of the extension.
