Query menu & panel

A dedicated tab for exploring your graph and tables — separate from a runnable code cell in a note, though it shares the same execution engine underneath.

The Query menu

Cmd+Shift+Q
New Query — opens a fresh Query panel tab, empty and ready to write in.
Stock Queries
A submenu of ready-made queries, split into a SPARQL branch and a SQL branch (see below) — pick one to open it pre-filled in a new panel.
Saved Queries
Your own saved queries, in two scopes you can toggle between: Thoughtbase (saved with this project) and Global (available across every project). Saved queries can be edited from this menu too.

The panel itself

The Query panel is a split view: an editor on top (40% of the height by default) and a results table below (60%). A language dropdown switches the editor between SPARQL and SQL mid-query — useful when you're not sure yet which one answers your question. The toolbar has Run, Save, and Format, plus the last run's execution time and result count.

Results table
Sortable — click a column header to toggle ascending/descending.
Copy as…
Turns the current results into something you can paste into a note: List or Table (a :::query-list / :::query-table block, re-run live every time the note renders — see Result blocks), or Executable block (a plain ```sparql/```sql fence with your exact query, so you can keep refining it in the note itself — see Runnable cells).
Export CSV
Saves the current results table to a .csv file on disk — a one-off export, not a live block.

Stock SPARQL queries

Twelve queries covering common graph questions, ready to run or adapt:

All notes with tags
Every note alongside the tags filed on it.
Backlinks to note
Edit the target path in the query, then run it to see everything that links in.
Orphan notes
Notes with no inbound or outbound links.
Most-linked notes
Ranked by incoming link count.
Recently modified
Notes ordered by last-modified time.
All tags with counts
Every tag in use, and how many notes carry it.
Notes in folder
Edit the folder path in the query to scope it.
Typed outgoing links
A note's typed links (supports, rebuts, etc.) grouped by type.
Typed backlinks
The typed-link equivalent of Backlinks to note.
All sources with authors/year
Every ingested source and its bibliographic basics.
Most-cited sources
Sources ranked by how many notes cite them.
Sources missing metadata
Sources without an author, year, or title — candidates to clean up.

Stock SQL queries

All tables
Schema introspection — lists every table registered from a markdown table or CSV.
Describe schema
DESCRIBE your_table; — column names and types for a table you name.
Summarize
SUMMARIZE your_table; — per-column stats (min/max/nulls/approx-unique) via DuckDB's built-in.
Null rate per column
How complete each column actually is.
Top values for a column
A quick frequency count, edited to name the column you care about.
Saved query scope

A query saved as Thoughtbase-scoped travels with the project (useful for a query specific to this notebase's structure); one saved as Global shows up no matter which project you have open (useful for a general-purpose query like "orphan notes" you want everywhere). Switch scopes from the Saved Queries submenu.
