Docs/Right sidebar/Citations

Citations

The Citations panel lists every source the current note cites or quotes — one row per source, with a byline, an occurrence count, and (when the note quotes it) the specific excerpts pulled in. It's a bibliography for the note you're looking at, built from its [[cite::…]] and [[quote::…]] links rather than typed by hand.

How it works

The panel groups every cite and quote typed link in the note by the source it resolves to, so a source cited three times and quoted twice appears once, with both counts on the same row. It reads the note's own indexed thought:cites / thought:quotes edges to find which sources are in play, then re-scans the live editor buffer to count occurrences — so the counts track what you're typing, not just the last save. Edits are debounced before the panel re-queries, so fast typing doesn't trigger a query per keystroke.

Source row
Shows the source's title in italic and a byline (author, or "author and author," or "author et al." for three or more, plus the year when known) — the same metadata as the source's own entry. A chip on the right splits the count into cites and quotes, e.g. 3 cites and 2″ quotes.
Click a source row
Opens that source's own tab — the same detail view described in Left sidebar → Sources — scrolled to the top.
Expand a source
A disclosure triangle appears on any source the note actually quotes. Expanding it lists each quoted excerpt underneath, with a truncated preview of the quoted text and its locator (a page number, page range, or other location text) when the source has one.
Click an excerpt
Opens the source scrolled to that excerpt, rather than just to the top of the source — useful for jumping straight back to the passage you quoted in a long PDF or web capture.
Search and sort
The ribbon's search field filters by source title, source ID, author name, or quoted text — so you can find the source you cited by searching for a phrase you remember quoting. Sort between "Most cited" (the default) and alphabetical by title.

Gotchas

  • A citation key that doesn't resolve still gets a row. If a [[cite::id]] or [[quote::id]] points at a source ID with no matching entry in the graph, that source is skipped entirely — it never enters the group set, so it won't show up as a broken row. Only sources the graph can actually resolve are listed, whether or not they have a title.
  • A resolved source with no title reads as "uncited." If the source exists in the graph but has no title yet (a stub, or metadata still being fetched), its row shows the raw source ID in place of a title, in a warning color, with "N references · uncited" instead of a byline. It's still clickable — the warning is about missing metadata, not a broken link.
  • Bibliography blocks don't inflate the count. Notes that embed a rendered bibliography block don't have their citation counts doubled by it — the panel strips that block before counting, so the numbers reflect inline cite/quote links only.
  • No citations, no rows. A note with no cite or quote links shows a plain "No citations in this note" message — this panel only covers the source/excerpt typed links, not plain references links to other notes (see Backlinks for those).
