Docs/Export/Flashcards

Flashcards

The Anki Deck exporter turns explicit [!card] callouts into an .apkg file you can import into Anki — not a blanket "turn my notes into flashcards" converter. If a note has no card callouts, it contributes nothing to the deck.

Writing a card

A card is a callout with a --- divider splitting the front (prompt) from the back (answer):

Example

> [!card] Optional Deck ^cardid
> What is the capital of France?
> ---
> **Paris**

The leading > (blockquote form) is optional — a bare [!card] paragraph works too, same as any other callout. Both the deck name and the ^cardid block-id after it are optional.

Deck resolution

A card's deck name resolves in order:

1. Callout title
Whatever comes right after [!card] on that line — Optional Deck in the example above.
2. Frontmatter
The note's own cardDeck frontmatter field, if the callout didn't specify one.
3. Folder
The note's folder path, mapped to a deck path (e.g. notes/math/algebra.md → deck notes::math).
4. Default
Notes sitting at the vault root with no deck specified any other way fall into a deck literally named Default.

Card identity

A card's stable id is the trailing ^cardid on its callout line. Cards without one get an id assigned and written back into the note automatically on first export — so re-exporting after editing a card's text updates the same Anki card instead of creating a duplicate.
