Font size & zoom

Minerva has two separate controls for making text bigger or smaller, and they don't do the same thing. Editor font size resizes only the text inside the CodeMirror source editor. Zoom scales the entire window — sidebar, toolbar, dialogs, and the editor along with everything else. They're independent settings that happen to compound, since zoom scales the whole rendered page including whatever the editor's own font size is currently set to.

The two mechanisms

Editor font size
Resizes text in the source editor only — the sidebar, toolbar, and dialogs stay the same size. ⌘⇧= / CtrlShift= increases it, ⌘⇧- / CtrlShift- decreases it, in steps of 1px each press (View → Increase/Decrease Editor Font Size, src/main/menu.ts:482-491). View → Reset Editor Font Size has no default shortcut. Ranges from 10px to 24px, default 14px (src/renderer/lib/editor/font-size.ts:10-12), and persists across restarts in localStorage under editorFontSize (src/renderer/lib/components/Editor.svelte:253-254). There's no Settings-panel slider for it — the menu items and shortcuts are the only way to change it.
Zoom
Scales the whole window's UI — everything renders bigger or smaller together, not just the editor. ⌘+ / Ctrl+ zooms in, ⌘- / Ctrl- zooms out, ⌘0 / Ctrl0 resets to actual size (View → Actual Size / (unlabeled zoom in/out), src/main/menu.ts:478-480). These are Electron's built-in resetZoom / zoomIn / zoomOut menu roles, which drive webContents's zoom factor directly — Minerva doesn't implement its own zoom logic or clamp it to a custom range.

They compound, not replace

Zoom scales the entire rendered page, and the editor's font size is just a CSS pixel value on that page — so zooming in on a window where you've already bumped the editor font up to 20px gives you 20px text rendered at, say, 110% larger again. If text looks too big, check both controls rather than assuming one setting reset the other.

Gotchas

  • Zoom resets every launch; editor font size doesn't. Editor font size is saved to localStorage and survives restarts. Zoom is Electron's in-memory webContents zoom factor — Minerva doesn't persist it anywhere, so a zoomed window goes back to 100% the next time you open the app.
  • Zoom has no reset shortcut for the editor specifically. ⌘0 resets whole-window zoom to 100%; it does not touch your editor font-size setting. To get the editor back to its default 14px, use View → Reset Editor Font Size.
  • Editor font size is clamped, zoom isn't (by Minerva). The editor setting can't go below 10px or above 24px — the menu commands simply stop moving it further once you hit either end. Zoom uses Chromium's own built-in limits, which are much wider and not something Minerva restricts.
  • No Settings-panel control for either. Both are menu commands (with keyboard shortcuts) rather than fields in Settings — there's nothing to type a specific pixel size or zoom percentage into.
