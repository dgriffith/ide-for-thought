View operations

The View menu controls what's on screen — which panels are showing, how a note is displayed, the split layout, the theme, and text size. Almost every command has a keyboard shortcut, so you rarely need the menu itself once they're in your fingers.

Showing and hiding panels

Toggle Left Sidebar
View → Toggle Left Sidebar (⌘B) shows or hides the left rail — the Notes tree, Sources, Tags, and more.
Toggle Right Sidebar
View → Toggle Right Sidebar (⌘⇧B) shows or hides the right rail — backlinks, outline, properties, and the rest.
Toggle Conversations
View → Toggle Conversations (⌘⇧K) shows or hides the Conversations panel.
Cycle Preview Mode
View → Cycle Preview Mode (⌘⇧P) steps the current pane through Source, Preview, and side-by-side. See View modes.

Splitting the editor

Split Editor Right / Down
View → Split Editor Right (⌘\) and Split Editor Down (⌘⇧\) divide the window into panes so you can see two notes at once. See Split panes & windows.
Focus Next / Previous Group
View → Focus Next Group (⌘⌥→) and Focus Previous Group (⌘⌥←) move the cursor between panes.
Close Group
View → Close Group (⌘⇧W) closes the focused pane.

Theme

Theme
View → Theme picks a look directly — Dark, Light, High Contrast, or System.
Cycle Theme
View → Cycle Theme (⌘⇧T) steps through them without opening the menu. See Themes.

Zoom and font size

Actual Size · Zoom In · Zoom Out
View → Zoom In / Zoom Out scales the whole window; Actual Size resets it.
Editor Font Size
View → Increase / Decrease Editor Font Size (⌘⇧= / ⌘⇧-) resizes the editor text only, and Reset Editor Font Size restores it. Zoom and font size are independent and compound — see Font size & zoom.

The View menu also offers full-screen and developer tools at the bottom.

Windows / Linux

Every shortcut above uses Ctrl in place of ⌘.
