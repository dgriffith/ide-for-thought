Right sidebar

The right sidebar gives you context about the note you're reading. Each panel answers a different question: What links here? What does this note link to? What's its shape? What does it cite? Which notes are related? Panels don't change your writing — they're different lenses on the note in front of you, and they update as you move from note to note.

One exception

Every panel here follows the note you're reading, and changes as you move between notes. For views of your project as a whole — including Proposals, where the AI's suggestions wait for you — see the left sidebar.

The panels at a glance

Backlinks
Other notes that link to this one.
Outgoing links
The notes this one links out to.
Outline
A collapsible list of headings for scanning a long note fast.
Properties
A note's properties as simple, editable fields.
Citations
Every source this note cites or quotes, with excerpts.
Tags
This note's tags, shown as a hierarchy.
Related
Other notes that read alike, so you can find connections you didn't make by hand.
Footnotes
Every footnote in this note, and a heads-up about any that don't line up.
History
Every saved version of this note, and one click to put an old one back.
Tables
The data tables this note works with.
Heading graph
The note's headings drawn as a visual tree.
Bookmarks
The spots you've bookmarked within this note.
