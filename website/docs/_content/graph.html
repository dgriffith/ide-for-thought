Graph

Minerva can draw your notes as a graph: each note a box, each connection between two notes a line. It's a way to see what connects to what, find the notes nothing points at, and ask how two ideas are linked.

Opening the graph

View → Graph of the Thoughtbase, or Open Graph in the command palette, opens every note in your thoughtbase as one graph in a tab. To start from one note, right-click it in the Notes tree and choose Show in Graph: the graph opens centred on that note, showing what's one step away.

The tab keeps everything about the graph while it's open and across restarts: its filters, the note it's centred on, the notes you've pinned, and where you'd zoomed to.

A large thoughtbase draws at once and settles over a few seconds without holding up the rest of the app. Names appear as you zoom in.

What connects notes

The graph draws more than the links you write. Each kind of connection has its own colour, and the legend above the graph lists the kinds it drew:

References
A wiki-link in a note's text.
A field's name
A typed note's field that points at another note, such as an Event's location, labelled by the field.
Supports, rebuts, …
The argument relations between claims. A claim's supports field, a [[supports::…]] link and a thought:supports line in a Turtle block all show as the same Supports connection.
Tags
With Tags on, each tag is a small node joined to the notes that carry it. It's off at first, because a common tag ties together notes that have little else in common.

Click a kind in the legend to hide those connections, and again to show them.

Narrowing it down

Pick a Folder (its subfolders come too), a Type or a Tag to draw only those notes. Tick Hide orphans to leave out notes with no connections. The count beside them says how many notes and connections are drawn, out of how many there are.

Select a note and choose Focus on to see only what's within a step of it, with − and + to change how far. Whole graph goes back.

Finding your way

Find a note marks every note whose name matches what you type and centres on the first; press Enter for the next match and ⇧Enter for the one before.

Select a note and everything further than a step from it fades. Bright within's − and + change how far, without changing what the graph holds.

How are two notes connected?

Select one note, choose Trace from, then select the other. The shortest connection between them lights up, and its steps are listed above the graph, each with the kind of connection it takes: Prague —references→ Plan —references→ Budget. Only the connections drawn count, so hiding a kind in the legend traces around it. If nothing connects them, it says so. Esc or Clear ends the trace.

Arranging the picture

Drag a note to put it where you want it: it stays there, the rest arrange themselves around it, and the tab keeps the arrangement. Release all lets the pinned notes go back to the layout.

Working with notes in the graph

Double-click a note to open it. Right-click a note for the note menu: edit its properties, add a tag, or remove one. ⌘-click or ⇧-click picks several notes, and right-clicking one of them acts on them all.

List shows the same notes as text, each with its connections, for reading or moving through by keyboard.

One note's graph

The graph button in the right sidebar's Outgoing links panel opens the graph centred on the note you're editing, showing what's one step away, just as Show in Graph does. Use − and + beside Around to see further, or Whole graph to see everything.

Exporting the graph

Export saves the graph as an image: a PNG or an SVG, of this view (what's on screen, as you've zoomed it) or of the whole graph. The image is the graph as drawn, with what you've marked: a found note, a trace, the fading around a selected note. It has a key of the kinds of connection shown. SVG keeps every line sharp at any size; PNG is the one to paste into a slide or a message.

A graph of a view

Any type view with a field that links to another note, such as a task's blocks, can be drawn as a graph of just those notes, with a colour for each field. See The graph on the Objects page. A graph view embedded in a note exports as a still picture of the graph in web pages, PDFs and published sites.
