Ingest

Bring outside material — papers, articles, web pages, PDFs — into Minerva as sources you can cite, quote, and search right alongside your own notes. Add them by pasting a link, dropping in a file, or capturing a page straight from your browser.

At a glance

—
Adding sources — paste a web link or a paper's identifier, add a file from your computer, or import a whole reference library at once.
—
PDF ingest — pull the text out of a PDF so you can read, search, and quote it, including scanned documents.
—
Browser clipper — save the page you're reading with one click, no copy-paste required.
—
Citing & duplicates — reference a source from a note, and what happens if you add the same one twice.
Sources sit right beside your notes

Once you add a source, it keeps its own details and a readable copy of its text. It appears in the Sources panel, can be cited from any note, and turns up in search just like everything else you've written.
