Editor operations

The Edit menu holds the text commands that act on the note you're writing — the familiar undo and copy/paste, plus finding and replacing, inserting a template, and tidying lines. Most also carry a keyboard shortcut.

The basics

Undo · Redo · Cut · Copy · Paste · Select All
The standard editing commands at the top of the Edit menu, with their usual shortcuts (⌘Z, ⌘C, ⌘V, and so on). Undo history is per note.

Find and replace

Find
Edit → Find (⌘F) searches within the current note and steps through the matches.
Find and Replace
Edit → Find and Replace (⌘H) does the same, with a field to replace matches in the current note.
Find in Notes…
Edit → Find in Notes… (⌘⇧F) searches across every note in the thoughtbase, not just the open one. See Search.
Replace in Notes…
Edit → Replace in Notes… (⌘⇧H) replaces text across every note — a careful, base-wide find-and-replace.

Inserting and transforming

Insert Template…
Edit → Insert Template… drops a saved template into the note at the cursor — a quick way to reuse boilerplate or a standard structure.
Sort Lines
Edit → Sort Lines sorts the selected lines into alphabetical order — handy for lists and tables of contents.
Windows / Linux

Every shortcut above uses Ctrl in place of ⌘.
