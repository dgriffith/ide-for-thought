Backlinks

The Backlinks panel shows every note that links to the one you're reading. It's the reverse of the note's own outgoing links: instead of where this note points, it tells you what points here. The list keeps itself up to date, so when you link to this note from somewhere else, it appears here automatically.

Reading the panel

Each row is a note that links to the one you're viewing, shown by its title. A line at the top gives a running total. If a note links here more than once, each link is its own row, so the count reflects mentions rather than distinct notes.

Search
Type in the search field to narrow the list to notes whose titles match, live as you type.
Group by type
By default, links are grouped into collapsible sections by the kind of link — for example "supports" or "references" — each with a color and a count. Click a section header to fold it away, or use the buttons at the top to collapse or expand everything at once.
Sort alphabetically
Switch the sort option to list every backlink in one flat list ordered by title. Each row then carries a small colored badge showing its link type.
Click to open
Click a row to open that note. When you come back, the panel is just as you left it — your search text and folded sections are remembered.
Drag to reuse
Drag a row into another note to drop in a link to it, the same way you can drag a note from the sidebar.

When nothing links here

If no note links to the one you're viewing, the panel says "No backlinks found." That's normal for a brand-new note or one you simply haven't linked to yet. If backlinks do exist but your search doesn't match any of them, it says "No matches" instead, so you can tell whether the panel is empty because nothing links here or because your search is too narrow.
