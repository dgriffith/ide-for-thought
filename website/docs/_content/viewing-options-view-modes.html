View modes

You can look at a note as the plain text you type, as the finished, formatted page, as a mindmap of its outline, or with the text beside either one. Each pane sets its own mode, so you can be editing one note while reading another in the same window. Switching modes never changes your note — it's just a different way to look at the same content.

The modes

The mode belongs to the pane, not the note. Reopen a note later and it appears in whatever mode that pane was last set to.

Source
The plain text you type, ready to edit. This is where you'll want to be for hands-on work: fixing a link, adjusting a note's properties, or writing inside a cell.
Preview
The finished, read-only page, with everything formatted the way it will look — headings, callouts, math, diagrams, charts, and embedded media all shown live.
Side by side
Your text on the left and the formatted page on the right, in the same pane, so you can write and see the result at once. Chosen from the Mindmap, it puts your text beside the map instead.
Mindmap
The note's outline as a map: its title in the middle, its headings and list items as branches. You can reshape the note from here. See Editing a note as a mindmap below.

A plain-text file has nothing to format, so it only shows Source — the toggle doesn't appear.

Switching modes

There are two ways to change a pane's mode:

Toolbar buttons
Three buttons above the note — Source, Side by side, Preview, Mindmap — jump straight to that mode from wherever you are, so you can go from editing to the finished page in one click.
Cycle shortcut — ⌘⇧P
Steps the active pane through the modes in order: Source → Preview → Side by side → Mindmap → Source. The same command is in the View menu as Cycle Preview Mode.
Mindmap — ⌘⇧M
Shows the note as a mindmap, and again goes back to the editor. In the View menu as Mindmap.

Editing a note as a mindmap

The Mindmap mode shows a note's outline as a map you can reshape: add, rename, move, promote and fold its headings and list items, and find each change in the note's text. Every key and how it works is on the Mindmap page.
