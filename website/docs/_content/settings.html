Settings

Settings is where you shape how Minerva looks and works. Thirteen tabs cover different corners of the app — the writing experience, the AI, where new notes are filed, what the app is allowed to fetch. Most changes take effect right away, so you can try something and see the result.

The thirteen tabs

Editor
Tab size, wrapping, line numbers, and other editing preferences.
Appearance
Choose a theme and the font your notes are shown in.
Behaviors
App-wide toggles, and a way to bring back any dialog you told to stop asking.
Notes
Where new notes are filed when you split a note or save an excerpt.
Versioning
How long each note's saved versions are kept, and how much disk they may use.
Formatter
Turn each tidy-up rule for your writing on or off.
Object Types
The kinds of note your project knows about, and the fields each one expects.
Bibliography
Pick a citation style and language, and add more of each.
Web
Decide whether the AI can search and read the web, and which sites it may visit.
Sources
Bring in tags from your sources and choose which sites can be fetched.
Clipper
Connect the browser tool that sends web pages into Minerva.
Compute
Choose which Python setup runs the calculations in your notes.
AI
Set the default model, how hard it thinks, your access key, and voice dictation.
Skills
Import skills and set per-skill model overrides.
