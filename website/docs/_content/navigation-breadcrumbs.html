Breadcrumbs

A thin bar above the note title shows where the current note sits in your folders — each folder along the way, then the note's own name. It's just a signpost telling you where you are, plus a quick way to jump back to that folder in the sidebar.

What the trail shows

The bar lists each folder that contains the note, from the outermost inward, ending with the note's own name. A note filed under research, then interviews, shows as research › interviews › q3-notes. A note that isn't inside any folder shows just its own name.

Folder steps
One for each folder the note lives inside. Click any of them to reveal that folder in the sidebar.
The note's name
Always last, shown in italic. It isn't clickable — you're already looking at it.
Heading trail (optional)
You can turn on an extra trail of the headings your cursor currently sits under, in Settings → Behaviors. Click a heading to jump straight to it in the note. It's off by default because it updates as you move around, which some people find busy.

Clicking a folder

Click any folder in the trail to reveal it in the sidebar: Minerva switches to the Notes panel, opens that folder and everything above it, and scrolls it into view — so you can see what else is filed alongside the note you're reading.

As you move around

The trail updates the moment you switch to a different note or tab. When no note is open, the bar simply isn't there.
