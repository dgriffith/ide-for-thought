Thinking tools

The Learning, Research, and Analysis menus are ready-made thinking moves you run over the note you're looking at — steelman an argument, pull out its claims, quiz yourself on it, check a fact. Each one is a skill, and the set is yours to turn on and off, rearrange, or add to.

—
Making them your own — turn skills on and off, move and reorder them, or write your own.
You stay in control

A skill's result is a suggestion, never a silent change. Anything a skill wants to add or edit comes back for you to approve or reject first — see The propose → review → approve loop.
