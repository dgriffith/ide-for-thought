Docs/Navigation

Navigation

There are six ways to get from one note to another, and the fastest depends on what you already know. Know the command you want? The palette. Know the name? Quick switch. Following a link someone already laid down? A wiki-link. Only remember a phrase? Search. Lost track of where you are? The breadcrumb trail. Went one note too far? Step back.

At a glance

⌘K
Command palette — run a command or action by name. No notes, sources, or queries here.
⌘P
Quick switch — jump straight to a note, source, or saved query by name.
click
Wiki-links — follow a [[link]] where it's rendered, with a hover preview first.
⌘⇧F
Search — find any word or phrase across the full text of every note.
—
Breadcrumbs — a persistent trail above the note title; no shortcut, it's always there.
⌘[ / ⌘]
Back / forward — retrace your steps like browser history.
Windows / Linux

Every shortcut above uses Ctrl in place of ⌘.
