Docs/Conversations/Slash commands

Slash commands

Slash commands are a keyboard shortcut into everything you'd otherwise reach with a menu or a button. Type / at the start of a message and a small menu appears with a couple of housekeeping commands for the conversation itself, plus any thinking tools that have a shorthand — so you can compact a long thread, or fire off a quiz or a summary, without lifting your hands from the keyboard.

Opening the menu

In the conversation composer, type / as the very first thing in an otherwise empty message. A menu floats up above the composer showing the commands you can run. Keep typing to filter the list — /sum narrows to /summarize, and so on. The menu only appears while what you've typed is a single unbroken command word; add a space, or start with anything other than a slash, and you're just writing an ordinary message.

Nothing runs until you pick it

Opening the menu changes nothing on its own. A command only fires when you choose it — and anything a thinking tool wants to change your notes still comes back as a draft for you to accept or discard. See The propose → review → approve loop.

Built-in commands

Two commands act on the conversation itself. They're always available, at the top of the menu.

/clear
Files the current conversation away and opens a fresh one in its place, carrying over the same starting note and assistant so you can pick up a new line of thought without losing the old thread. A brand-new, empty conversation is left alone, so there's no harm in reaching for it out of habit.
/compact
Summarizes the earlier turns of a long conversation into a shorter one and swaps it in, keeping the gist while trimming the length. The original is filed away untouched. A conversation that's already short is left as-is.

Thinking-tool commands

Below the built-ins, the menu lists thinking tools that carry a slash shorthand — the same skills you'd otherwise launch from the Learning, Research, and Analysis menus. Picking one from the slash menu is just a faster way in: it opens the tool exactly as the menus would, running straight away when the tool needs nothing else from you.

Which tools show up depends on which skills are turned on and whether they declare a shorthand, so your list may differ. A few of the stock ones:

/summarize
Condense the note you're working with into a short summary.
/quiz
Turn a note into quiz questions to test yourself.
/steelman
Build the strongest possible version of an argument.
/find-sources
Suggest sources that would back up or challenge a claim.
/visualize
Propose a chart for the data in a note.
Your own shortcuts

Skills you add yourself can carry a slash shorthand too, and they'll appear here alongside the stock tools. They can't take over one of the built-in names, so /clear and /compact always mean the same thing. For how to give a skill a slash command, see Thinking tools.

Getting around the menu

The menu is built for the keyboard:

↑ ↓
Move up and down the list. The selection wraps around at either end.
⏎ or ⇥
Run the highlighted command.
Esc
Dismiss the menu and leave what you typed in place, so you can carry on writing an ordinary message.
Mouse
Hover to highlight, click to run — whichever's closer to hand.
