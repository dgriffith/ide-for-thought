Docs/Viewing options/Themes

Themes

Minerva ships three appearance themes — Dark, Light, and High Contrast — plus a System option that follows your OS setting. Switching is instant: pick one from Settings, the status bar, or a shortcut, and the whole app repaints immediately. There's no restart, and no per-note override — theme is a whole-app setting.

The themes

Every theme is a set of CSS custom properties (--bg, --text, --accent, --border, and related tokens) defined in src/renderer/styles/global.css. The default tier lives on :root; the other two are keyed off a data-theme attribute on <html>, so switching is a single attribute swap rather than a stylesheet reload.

Dark (default)
Minerva's default look — a warm, Catppuccin-inspired dark palette ("Honey"): ink-toned backgrounds, soft warm-white text, and a honeyed amber accent. Defined on :root with no data-theme attribute set.
Light
The same warm palette inverted onto a pale paper background, with darker text and a deeper amber accent — reads like the dark theme's daytime twin rather than a generic light mode. [data-theme="light"].
High Contrast
A stark black-on-white palette with a dark title bar retained over the light body. Signal colors (sage, rust, iris) and highlight tints are individually darkened so every combination clears WCAG AA (4.5:1). Built for maximum legibility, not aesthetics. [data-theme="contrast"].
System
Not a fourth palette — it follows your OS light/dark setting, resolving to Dark or Light and updating live if you change your OS appearance while Minerva is open. This is the default on a fresh install.

Switching themes

Three equivalent ways to change the theme, all reading from and writing to the same list so labels never drift between surfaces:

Settings → Appearance
Open Settings and select the Appearance tab, then choose a theme from the Theme dropdown. The change applies live as you pick — no "Apply" or "OK" step needed, and no restart.
Status bar
Click the theme label in the status bar to open a small picker listing all four options; click one to switch immediately.
⌘⇧T
Cycles through Dark → Light → High Contrast → System → Dark, without opening any menu.

Your choice is stored in localStorage, so it's per-machine — it isn't part of the project and doesn't travel with the notebase or sync between devices.

Gotchas

  • Whole-app, not per-note. There's no way to pin one note or window to a different theme — every open window reflects the same stored preference.
  • "System" isn't a distinct palette. It's an auto-selector that resolves to the Dark or Light token set depending on your OS appearance, and updates live if the OS setting changes while Minerva is running.
  • No custom CSS override. Themes are fixed token sets shipped with the app; there's currently no user stylesheet or theme-editing surface to define your own.
  • Exports don't inherit your theme. HTML and PDF exports (src/main/publish/exporters/note-html/style.ts) use their own fixed, print-friendly light stylesheet, independent of whichever app theme is active — a note exported while you're in High Contrast or Dark looks the same as one exported in Light.
