Docs/Ingest

Ingest

Bringing external material into a thoughtbase — papers, articles, web pages, PDFs — as Sources you can cite, quote, and query alongside your own notes. Five ways in from the File menu, a quick paste into the Sources panel, drag-and-drop, or a browser extension that captures the page you're already reading.

At a glance

—
Adding sources — URL, DOI/arXiv/PubMed, a local file, or a bulk BibTeX/Zotero import.
—
PDF ingest — text-layer extraction, and the OCR handoff for scanned PDFs.
—
Browser clipper — a Chrome extension that captures the page you're reading, no copy-paste required.
—
Citing & duplicates — referencing a source from a note, and what happens when you ingest the same one twice.
A Source is a first-class citizen

Once ingested, a source lives under .minerva/sources/<id>/ — its own metadata, extracted body, and (for PDFs and web pages) the original file — right alongside your project's git history. It shows up in the Left sidebar's Sources panel, can be cited from any note, and is queryable like anything else in the graph.
