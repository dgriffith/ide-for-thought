Docs/Editor/Keyboard shortcuts

Keyboard shortcuts

Every shortcut the editor answers to, gathered in one reference: inline formatting, file and editing commands, and the navigation shortcuts documented in depth elsewhere. All bindings live in src/renderer/lib/editor/command-registry.ts (formatting and text commands, dispatched through CodeMirror's keymap) and src/renderer/lib/keymap/handle-keydown.ts (app-level navigation, bound at the window). On Windows and Linux, ⌘ becomes Ctrl and ⌥ becomes Alt — every combo below follows that swap unless noted.

Formatting

Inline and insert commands from COMMAND_REGISTRY. Toggle commands wrap or unwrap the current selection — pressing the same shortcut again on already-formatted text removes the markers. See Markdown formatting for the underlying syntax each one produces.

⌘B
Toggle bold — wraps the selection in **…**, or drops the cursor between a fresh pair of markers with nothing selected.
⌘I
Toggle italic — wraps the selection in *…*.
⌘E
Toggle inline code — wraps the selection in backticks.
⌘⇧X
Toggle strikethrough — wraps the selection in ~~…~~.
⌘⇧Y
Toggle highlight, cycling color on repeat presses — yellow → green → blue → pink → orange → plain (unwrapped). Y is mnemonic for yellow, the default color. Mod-Shift-H was the more obvious pick but was already claimed by the menu's Replace-in-Notes accelerator, so this shortcut uses Y instead.
⌘K
Insert a markdown link — [selected text](url), or [](url) with the cursor in the brackets if nothing's selected. This is the editor's insert-link command, distinct from the app-level command palette's ⌘K — the palette only opens when the editor isn't the one capturing the keystroke first.

Headings, quotes, lists, task lists, tables, horizontal rules, footnotes, wiki-links, and typed links are all reachable from the editor's Insert/Format menus and the command palette, but ship with no default key binding (defaultKey: '' in the registry) — there's simply nothing to press for them yet.

Shortcuts are user-remappable

Every entry in COMMAND_REGISTRY can be rebound from Settings — overrides are stored in localStorage and merged over the defaults at startup (resolveKeyBindings()). The bindings on this page are what you get out of the box; check Settings if a combo doesn't match what you're seeing.

File & editing

Saving, undo/redo, and text manipulation commands.

⌘S
Save now. Minerva autosaves on a debounced ~1000ms timer, so this isn't strictly necessary to avoid losing work — but it's not a no-op either: it flushes any pending autosave and writes immediately, then refreshes tags, the right sidebar, and backlink/alias caches on the spot rather than waiting for the timer.
⌘Z
Undo, via CodeMirror's standard history keymap (bundled in basicSetup).
⌘⇧Z
Redo.
⌘D
Duplicate line — with no selection, copies the current line directly beneath itself; with a selection, duplicates the whole selected region.
⌥↑ / ⌥↓
Extend or shrink the selection outward/inward through a sequence of enclosing scopes — word, bracket/quote pair, line, sentence, paragraph, heading section, whole document — remembering each step so shrinking retraces exactly what extending grew.
⌘⇧U
Toggle case of the selection (or the word under the cursor with nothing selected): all-lowercase → UPPERCASE → Title Case → lowercase.
Ctrl⇧J
Join lines — merges the current line with the next (or every line in a multi-line selection) into one, separated by a single space. This binding doesn't swap to ⌘ on Windows/Linux — it's Ctrl-Shift-j in the registry on every platform.
⌘⇧V
Start or stop voice dictation into the editor at the cursor.
⌘F
Open CodeMirror's built-in search panel, scoped to the current editor tab only. Not the same as project-wide search — see the gotcha below.
⌘H
Open the same panel with replace enabled, scoped to the current tab.
⌘F / ⌘H are per-tab, not project-wide

These open CodeMirror's own search panel inside whichever note is focused. For a search across every file in the project, use Find in Notes… (⌘⇧F) instead — same underlying idea, much larger scope. If a search you expect to span the whole project is only turning up matches in the file you already have open, you pressed the un-shifted version.

Navigation

Shortcuts that move you around the app rather than editing text. Each one has its own page with the full mechanics — this is just the complete list in one place, so you don't have to go hunting across the docs for a shortcut you half-remember.

⌘K
Open the command palette — a do-anything launcher over commands and actions.
⌘P
Quick switch — jump to any note, source, or query by name.
⌘⇧F
Find in Notes… — project-wide search across every file's actual content.
⌘[ / ⌘]
Back / Forward through your navigation history.
⌘⇧P
Cycle the active pane's view mode — Source → Preview → Editor + Preview → Source.
⌘\ / ⌘⇧\
Split the editor right or down.
⌘⇧N
New window — opens a second, blank Minerva window.
⌘N
New Note — prompts for a name and, optionally, a starting template.
⌘G
Go to line, when a note is focused.
⌘⇧Q
New query tab, when a project is open.
⌘⇧I
Open a conversation with the assistant.
⌘⇧B
Toggle the right sidebar.
⌘⇧T
Cycle the theme.
⌘W
Close the active tab, when one is open.

Gotchas

  • ⌘P is Quick switch, not a preview toggle. Unlike some other markdown editors, Minerva reserves ⌘P for Quick switch. Cycling the preview mode is ⌘⇧P instead, matching the Linear / VS Code convention rather than Obsidian's.
  • Join Lines doesn't follow the Cmd/Ctrl swap. It's bound as Ctrl-Shift-j in COMMAND_REGISTRY on every platform, including macOS — the one formatting/editing shortcut on this page that isn't ⌘ on Mac.
  • ⌘F/⌘H vs ⌘⇧F/⌘⇧H. The un-shifted pair searches only the current tab (CodeMirror's own panel); the shifted pair searches the whole project (Find in Notes…). Easy to reach for the wrong one out of habit from a single-file editor.
  • Most paragraph-level formatting has no default key. Headings, quotes, lists, task lists, tables, horizontal rules, and footnote insertion are registry commands with an empty defaultKey — reach them from the Insert/Format menus, the command palette, or bind your own key in Settings.
  • Every shortcut is remappable. If a combo on this page doesn't do what's described, check Settings for a user override before assuming the docs are stale.
