Docs/Settings/Appearance

Appearance

Two controls live on this tab: which theme the whole app uses, and which font the markdown editor and preview render in. Both apply live as you change them — there's no "Apply" step, and neither setting travels with a project; they're stored per-machine.

Theme

The Theme dropdown offers Dark, Light, High Contrast, and System. This tab is just one of three equivalent places to change it — the status bar and the ⌘⇧T shortcut cycle the same setting. The mechanics — what each theme looks like, how System tracks your OS, where the preference is stored — are covered in full on the Themes page; this tab is just the Settings-dialog surface for picking one.

Content font

The Content font dropdown changes the typeface used for note text — in both the CodeMirror editor and the rendered preview. It does not touch the app's own interface: menus, sidebar labels, dialog text, and every other piece of chrome stay on the system UI font regardless of what you pick here. The setting writes a single CSS custom property, --content-font-family, which the editor's .cm-content and the preview pane both read; everything else in the app never references that variable, which is what keeps the two scopes separate.

Minerva default (Plex)
No override — content falls back to Minerva's own monospace stack (IBM Plex Mono and friends). The default look, unchanged.
System Sans
-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif — your OS's UI sans, for a prose-first reading feel.
Serif
Georgia, "Times New Roman", Cambria, serif — a book-like serif for long-form notes.
Monospace
ui-monospace, "SF Mono", "JetBrains Mono", "Fira Code", Menlo, monospace — a generic monospace stack that takes whichever of those faces is installed.
JetBrains Mono
Named preference for JetBrains Mono specifically, falling back through standard monospace faces if it isn't installed.
Berkeley Mono
Named preference for Berkeley Mono (and its TX-02 alias), same fallback pattern.
System mono
ui-monospace, SFMono-Regular, Menlo, Monaco, "Cascadia Mono", monospace — your OS's default monospace face instead of Plex Mono.

Gotchas

  • The named mono presets don't install fonts. Picking "JetBrains Mono" or "Berkeley Mono" only sets a font-family preference — if that face isn't already installed on your system, the browser falls through to the next name in the stack (ultimately Menlo/SFMono-Regular), so the note pane will silently keep looking like the fallback rather than the one you chose.
  • Chrome is never affected. If you're expecting a "reading font" that also restyles the sidebar or menus, that's not what this control does — it's scoped to --content-font-family, which only the editor content and preview read. The rest of the UI always uses the system font.
  • Per-machine, not per-project. Like theme, the content font is stored in localStorage — it's a preference for this install of Minerva, not something that travels with the notebase or syncs to another device.
