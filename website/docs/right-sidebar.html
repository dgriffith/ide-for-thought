Right sidebar

The right sidebar is context about the note in front of you — twelve panels, each answering a different question about it. What links here? What does it link to? What's its shape? What's pending review? What does it cite? None of them edit your prose directly; they're lenses on the graph, the frontmatter, and the AI review queue, all pointed at whatever you're currently looking at.

One exception

Every panel below is scoped to the note you have open — except Proposals, which is project-wide by design: pending AI writes aren't naturally a per-note concern, so it shows you everything regardless of which note is active.

The twelve panels

Backlinks
Notes that link to this one — the incoming side of the graph.
Outgoing links
Every wiki-link this note makes — the outgoing side.
Outline
A collapsible heading tree, for scanning a long note fast.
Properties
Frontmatter as editable typed rows, instead of raw YAML.
Proposals
Approve or reject pending AI writes, one keystroke at a time.
Citations
Every source this note cites or quotes, with excerpts.
Tags
This note's own tags, shown as a hierarchy — read-only.
Related
Notes that read alike, found by semantic similarity.
Footnotes
Every footnote in this note, plus a linter for dangling ones.
Tables
Which SQL-referenced tables this note mentions actually exist.
Heading graph
The same headings as Outline, drawn as a spatial tree.
Bookmarks
This note's bookmarks, filtered from the project-wide list.
