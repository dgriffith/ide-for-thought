Bibliography & citations

Two exporters for getting your citations into a form other reference tools understand, plus the settings that control how a citation actually renders.

BibTeX

Exports every cited source as a single .bib file, one entry per source, keyed with a deterministic author-year-firstword citekey (e.g. smith-2020-functions — stop-words like "the" are skipped when picking the title word). Scope to a single note, a folder, or the whole project.

Citekeys are stable per export, not forever

The same source set produces the same keys every time. But adding a new source to your library can shift a collision suffix (smith-2020a → smith-2020b) for entries it now collides with — so don't treat a citekey as a permanent identifier across exports. Sources themselves are still matched by DOI/arXiv id/etc. on re-import, not by citekey.

Pandoc

For anyone who wants Word, PDF, or another format Pandoc itself produces: exports a single note as markdown (with [[cite::id]] rewritten to Pandoc's [@citekey] form) alongside a bibliography.json (CSL-JSON) and a generated README.md with the exact pandoc command to run, including your chosen citation style. There's no one-click "formatted bibliography .docx" exporter — Pandoc is the escape hatch for that, not a built-in.

Bibliography settings

Controls how citations render across every exporter that formats them (Pandoc's generated command, and the note-html/tree-html exporters):

Citation style
A dropdown of bundled and imported CSL styles. Defaults to APA; an unrecognized or missing style falls back to APA automatically rather than failing.
Import .csl style…
Bring in a citation style Minerva doesn't ship — any valid CSL .csl/.xml file.
Locale
Defaults to en-US, with the same fallback behavior as style. Import a custom locale the same way as a style.
