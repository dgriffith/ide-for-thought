# Rent vs supply — a dozen metros

A quick cut of the same twelve metros in [[city-rents.csv]], captioned so it
registers as a queryable table. The pattern to notice: as homes-per-thousand
falls, median rent climbs — with Detroit sitting apart on vacancy.

Table: Metro rent and supply
| metro         | homes_per_1k | median_rent | vacancy_rate |
|---------------|--------------|-------------|--------------|
| Detroit       | 500          | 1100        | 22.0         |
| Austin        | 480          | 1500        | 7.5          |
| Chicago       | 445          | 1750        | 6.0          |
| Seattle       | 430          | 2100        | 4.5          |
| Boston        | 405          | 2600        | 3.0          |
| San Francisco | 390          | 3300        | 3.5          |

The full twelve-row dataset lives in the shipped CSV; this captioned table is a
representative slice for eyeballing the correlation.
