# Testing thoughtbase (#1522)

A small, purpose-built thoughtbase the eval cases run against, deliberately
shaped so every stock skill has something real to bite on. Theme: **does
building more housing lower rents** — a live debate that naturally carries
arguments, data, sources, and vocabulary. All prose is original (license-clean).

What it exercises, and the skills that need it:

- **Argument notes** — `upzoning-lowers-rents.md` (claim + grounds + warrant,
  an embedded `thought:Claim`, KaTeX, a mermaid diagram, typed links, tags),
  `induced-demand-objection.md` (the opposing position),
  `rent-control-argument.md` (one obvious load-bearing/weak link) — feed
  steelman, decompose-into-claims, load-bearing-claim, doublecrux, find-tensions,
  and the claim-scoped skills (find-opposing/supporting-arguments, check-facts, …).
- **A source + excerpt** — `.minerva/sources/glaeser-2005/` (meta.ttl + body.md)
  and `.minerva/excerpts/glaeser-supply-elasticity.ttl` — feed the source-scoped
  skills (propose-source-summary, extract-key-claims) and `cite::`/`quote::`.
- **Data** — `city-rents.csv` (a real negative correlation between supply and
  rent, plus a clear vacancy outlier) and a captioned `Table:` in
  `notes/data/rent-supply-table.md` — feed find-correlations / find-outliers /
  generate-visualizations (live runs; their packaged prompt is data-independent).
- **Vocabulary** — `notes/glossary/*.md` — feed add-term-to-glossary,
  generate-glossary, deep-dive, explain-like-im.
- **A messy note** — `messy-braindump.md` — feeds crystallize, fill-out-note,
  summarize, synthesize.
- **Loose / oddly-named notes** — `vienna.md`, `Draft note ABOUT zoning (rename
  me).md` — feed organize-by-topic and tidy-filenames.

## Derived vs authored

Only the notes, the CSV, and the `.minerva/sources` + `.minerva/excerpts`
fixtures are hand-authored and tracked. The graph/search/table **indexes**
(`config.json`, `graph.ttl`, `search-index.json`, …) are regenerated by the
harness on every run (`initGraph → indexAllNotes → walkAndIndexSources/Excerpts`)
and are gitignored — never commit them.
